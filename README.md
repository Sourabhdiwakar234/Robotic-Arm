# Robotic Arm

A 4 Degrees of Freedom (DOF) robotic arm designed using SolidWorks, primarily aimed for demonstration and understanding of robotic movement principles. This model was created as part of an induction project in the ARC (Automation & Robotics Club).

## Project Overview

This project focuses on the mechanical design of a robotic arm that showcases basic articulation and joint movement without involving any electronics or actuators. The robotic arm consists of multiple custom-designed parts, all created and assembled in SolidWorks.

## Purpose

The primary goal of this robotic arm is to serve as an introductory project for ARC inductions. It helps students and beginners to understand:
- CAD design and assembly workflow in SolidWorks
- The structure and kinematics of a 4 DOF robotic system
- Design considerations in robotic mechanisms

## Features

- Fully CAD modeled using SolidWorks
- 4 Degrees of Freedom design (Base rotation + 3 joint movements)
- No motors or wiring required (mechanical only)
- Suitable for simulation, demo, or 3D printing

## Files Included

- Multiple `.SLDPRT` files (Individual parts)
- One assembled part file (`ROBOTIC ARM PART 3 ASSEMBLED.SLDPRT`)
- Designed in SolidWorks 2023

## How to Use

1. Open the `.SLDPRT` files in SolidWorks.
2. Review or edit individual parts as needed.
3. Open the assembled file to visualize the full robotic arm.
4. Use the Motion Study or Mate features to simulate movements.
